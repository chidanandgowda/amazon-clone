## Hackathon Goal

Build a basic Amazon clone flow that works end to end:

`Login -> Product Listing -> Product Detail -> Add to Cart -> Cart Page`

## Team Rule

Do not wait for perfect code.
Build one small working feature at a time.

## Minimum Deliverable

Each teammate should be able to show:

- what they built
- what file(s) they worked on
- what prompts they used with AI
- what still needs fixing
