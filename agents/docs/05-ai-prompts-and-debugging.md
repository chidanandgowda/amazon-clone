# AI Prompts And Debugging

## Mental Model

You are not coding.
You are solving problems using AI.

## Best Practice

Do not ask AI:

`Build Amazon clone`

Ask AI:

- `Create product card UI`
- `Create signup API using Express and MongoDB`
- `Explain this code`
- `Explain this error and fix step by step`

## Recommended Prompts

### Setup

`Explain how to create a React app using Vite and Node.js backend step by step for beginners`

### Student 1

`Create a React component to display product cards with image, title and price using dummy data`

### Student 2

`Create a React page to show product details with title, image, description and add to cart button`

### Student 3

`Create a React cart page showing list of items with quantity and remove button`

### Student 4

`Create signup and login APIs in Node.js Express with MongoDB step by step for beginners`

### Student 5

`Create an API to return list of products and single product by id in Express`

### Student 6

`Create APIs for cart: add item, remove item, update quantity using Node.js and MongoDB`

### Database

`Explain MongoDB schema for user, product and cart in simple terms`

### Frontend To Backend

`How to fetch data from API in React using axios`

## Debugging Flow

When stuck:

1. Copy the error
2. Paste it into AI
3. Ask: `Explain this error and fix step by step`

## Common Problems

### `Code not working`

Normal.

### `Errors everywhere`

Good. It means you are actually trying things.

### `I don’t understand anything`

Expected.

## Final Deliverable

Each teammate should be ready to show:

- working feature
- code they wrote
- prompt(s) they used
- issue they fixed

## Final Reminder

For the next 3 to 4 hours:

- ignore perfection
- ignore fear
- ignore comparison

Focus on only one question:

`Can I make this one feature work?`
