# Project Overview

## Project Name

Amazon Clone

## Objective

Build a beginner-friendly e-commerce demo where users can:

- sign up
- log in
- view products
- open a single product
- add products to cart
- update or remove cart items

This is a hackathon project, so the target is not production quality.
The target is a working demo with clear ownership across all 6 team members.

## Core Stack

- Frontend: React with Vite
- Backend: Node.js with Express
- Database: MongoDB Atlas
- Version Control: Git + GitHub
- Editor: VS Code

## Existing Repo Notes

- `frontend/` already exists and is a Vite React app.
- `backend/` already exists but is still minimal and needs setup.
- `design/` contains reference screens for product listing, product detail, and cart.

## Feature Scope

### Frontend

- Product Listing page
- Product Detail page
- Cart page
- Login and Signup screens if time allows

### Backend

- Auth APIs
- Product APIs
- Cart APIs

### Database

- User collection
- Product collection
- Cart collection

## Final Demo Flow

The final demo should ideally work like this:

1. User signs up or logs in
2. User opens product listing page
3. User opens product detail page
4. User adds item to cart
5. User goes to cart page
6. User updates quantity or removes item

## Success Criteria

- frontend runs locally
- backend runs locally
- MongoDB Atlas is connected
- APIs return correct data
- pages are connected to APIs
- each team member completes their assigned part
